01 — About Me

The Engineer
Behind the Proofs

Hi, I'm Srishti — a recent Computer Science graduate focused on zero-knowledge proof systems, cryptographic protocols, and systems programming in Rust.

My engineering work lives in Rust — implementing proving-system components from scratch: finite-field arithmetic, FFT/IFFT, polynomial commitments, Merkle trees, Fiat-Shamir transcripts, and FRI folding. I care deeply about correctness, performance, and building intuition at the implementation level rather than just the theory level.

I started with the fundamentals — fields, groups, polynomials — and built up to full proving pipelines: a STARK prover and a KZG polynomial commitment scheme, both from scratch. I've also studied production ZK codebases like zkSync's Airbender to see how these concepts hold up at scale.

The intersection of Rust's type system and provable computation is where I feel most at home — proving correctness by construction, not by hope.

// Prove correctness of an execution trace
fn prove(trace: Vec<FieldElement>) -> StarkProof {
  let poly = interpolate(&trace);
  let lde = low_degree_extend(&poly);
  let root = merkle_commit(&lde);
  let comp = composition_poly(&poly, &constraints);
  fri_fold(comp, &mut transcript)
